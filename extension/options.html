grAImmer

Rule-based checking, English only. Nothing you type leaves the browser — there is no server and no network request.

What to check

What to leave alone

Personal dictionary

Added words are treated as correct, not skipped. So Grafana stops being flagged, while Graffana is still caught and can be corrected to it.

Sites

To turn grAImmer off for one site only, click its toolbar icon while you are on that site. Useful for a web IDE or an internal tool where the underlines are noise.

Code editors are skipped automatically. Monaco, CodeMirror and Ace are left alone wherever they appear — prose rules are simply wrong in source code.

Google Docs cannot be supported. It paints text to a canvas, so there are no text nodes for any extension to read. This is a limitation of Docs, not of grAImmer.

Slack asks extensions not to run via a data-gramm="false" attribute that its editor sets automatically. grAImmer ignores it, because that flag exists to stop extensions writing into the editor and grAImmer never does — underlines are drawn on a separate layer. If you would rather it respected the request, turn grAImmer off for Slack from the toolbar icon.
